Project Overview

This is a replication of the popular audio synthesizer Mini Moog, which was released in the 1970s. The aim of this project was to learn about audio synthesis and how to implement it in a digital environment.

What I Learnt

Coding all of these systems from scratch really gave me a better understanding of how various systems are tied together on the backend and highlighted many areas where I can optimise my code and improve its readability. I also got a lot more experience with inheritance, polymorphism, and working with pointers while setting up the entity manager.
