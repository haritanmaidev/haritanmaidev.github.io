Project Overview

Pushy Plushy is cute and chaotic 2-4 player party game where players compete against each other in 10 different mini-games. Each mini-game has various modifiers that changes how the game is played, making them feel different and unique every run. Players are also given tools and weapons based on the mini-game to compete and earn the most points.

What I Learnt

Initially, this system was written in C# which had major performance issues as it had to run the cellular automata algorithm for about 500K+ times per second on the CPU to produce decent results, and increasing the grid size made it impossible to run. This problem was solved by using Compute Shaders written in HLSL, which runs on the GPU to parellely process the simulation. The GPU version performed significantly better, it managed to run the algorithm accross 4M+ cells per frame and gave 200FPS which means the total amount of calculations were 800M+ (4,000,000 cells x 200 frames per second). Making this transition from C# to HLSL was quite challenging as I have limited experience with shader programming, so this was a steep learning curve. In the process of practicing PCG code beforing starting this project get a grasp of how PCG works, I made a seed-based basic solar system generator along with a perlin noise terrain mesh generator.
