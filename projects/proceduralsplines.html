Project Overview

This project explores a procedural spline tool within Unity through two implementations. The first is a custom Catmull-Rom Spline tool that allows easy manipulation of splines to form complex paths through collision-based deformation, control handles, and adjustable parameters such as curvature control, segment point offsets, segment resolution, closed-loop splines, and Perlin noise. The second focuses on procedural mesh generation along both Catmull-Rom and Bézier splines, with extended functionality of mesh generation along Bézier splines, to generate a roller coaster-style geometry.
