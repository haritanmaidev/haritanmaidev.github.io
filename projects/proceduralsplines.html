Project Overview

This is a remake of the classic arcade game Robotron: 2082, a fast paced 2D top-down roguelike released in early 1980s. The aim is to defeat endless waves of robots, rescue humans, and earn as many points as you can.

C++ SFML
Responsibilities
Gameplay Programming, Game Systems Programming, UI Programming, AI Programming, Low-Level Programming
Development Time
5 Weeks
Grade
First Class

Systems & Features

  • SFML Setup
  • Input System
  • Custom Collision Detection
  • Game Loop Manager
  • Custom Scene Manager
  • Game Object Base Class
  • 9 Character Classes
  • 5 Projectile Classes
  • Entity Manager
  • Wave System & Wave Difficulty Scaling System
  • Points System
  • Audio Manager
  • UI - Main Menu, Pause, Gameplay
  • Modern C++: Smart *, std::optional, const&, override, Member Init Lists

What I Learnt

Coding all of these systems from scratch really gave me a better understanding of how various systems are tied together on the backend and highlighted many areas where I can optimise my code and improve its readability. I also got a lot more experience with inheritance, polymorphism, and working with pointers while setting up the entity manager.
