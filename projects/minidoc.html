Project Overview

This is an educational game where the player must appropriately treat and manage various patients with varying conditions. The game teachs the player about the generic names of widely used medicine, how blood transfusion works, and CPR through a mini-rhythm-game. All the relevant learning materials can be found during gameplay, constantly letting the player correct their mistakes.

Unity C# UI
Responsibilities
Gameplay Programming, UI Programming
Development Time
4 Weeks

Systems & Features

  • Patient Types: Med, Blood, CPR
  • Patient Details Randomizer
  • UI Document for Patient Reports
  • Non-Diegetic & Spatial UI for interactions
  • Object Pooled Patient Spawner
  • Blood Transfusion Solver
  • Items & Item Storage Shelfs
  • Points System

What I Learnt

Working on the above mentioned systems helped improve my coding skills such as practicing better structure and readability in code. Additionally, I've never worked on a modular item storage system before so thats one more thing I'm now familiar with. The only tedious bit was making the CPR mini-game which took a lot of time to try different camera angles and different approaches for this rhythm game.
