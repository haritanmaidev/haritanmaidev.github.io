Project Overview

This project explores skeletal animation at a low-level where the infrastructure behind animation such as joint hierarchies that determine animated transforms from parent to children, GPU skinning to deform mesesh according to each vertex's joint weights, and keyframe data are implemented directly via C++ and DirectX11.
